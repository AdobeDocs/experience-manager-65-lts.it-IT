# Guida di Forms Designer {#form-designer-help}

AEM Forms Designer è un’applicazione desktop per la creazione e la gestione di moduli adattivi basati su PDF e XFA in Adobe Experience Manager Forms. Utilizza le risorse seguenti per iniziare, esplorare esempi e fare riferimento alle funzionalità di scripting di Designer per questa versione 6.5 LTS.

* [Utilizzo di Designer](https://www.adobe.com/go/learn_aemforms_designer_65_lts): panoramica dell&#39;area di lavoro di Designer e dei concetti principali di authoring.
* [Esercitazioni rapide di Designer](https://www.adobe.com/go/learn_aemforms_designer_quick_start_65_lts): esercitazioni dettagliate per iniziare a utilizzare Designer.
* [Esempi di Designer](https://www.adobe.com/go/learn_aemforms_designer_samples_65_lts): moduli di esempio scaricabili che è possibile aprire e adattare in Designer.
* [Nozioni di base sugli script di Designer](https://www.adobe.com/go/learn_aemforms_scriptingBasics_65_lts): introduzione agli script in Designer Form.
* [Riferimento script di Designer](https://www.adobe.com/go/learn_aemforms_scriptingReference_65_lts): riferimento completo per gli oggetti e i metodi di script in Designer.
* [Riferimento Designer FormCalc](https://www.adobe.com/go/learn_aemforms_formCalc_65_lts): riferimento completo per FormCalc, linguaggio di calcolo predefinito di Designer.
